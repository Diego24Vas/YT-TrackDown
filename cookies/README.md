# Cookies de YouTube para YT-TrackDown

Esta carpeta permite almacenar un archivo `cookies.txt` para autenticar peticiones de `yt-dlp`.

## ¿Por qué se necesitan cookies?
YouTube requiere que los usuarios inicien sesión para ver o descargar:
- **Videos con restricción de edad (+18)**.
- **Videos privados o no listados** a los que tu cuenta tenga acceso.
- **Videos exclusivos para miembros**.

## ¿Cómo obtener el archivo `cookies.txt`?
1. Instala en tu navegador favorito una extensión como:
   - **Get cookies.txt LOCALLY** (para Chrome, Brave, Firefox, Edge).
2. Ve a [YouTube](https://www.youtube.com) e inicia sesión con una cuenta mayor de 18 años.
3. Abre la extensión y haz clic en **Export**.
4. Puedes subir el archivo exportado directamente desde la **interfaz web** de YT-TrackDown (botón 🍪 Cookies) o copiarlo aquí con el nombre `cookies.txt`.
